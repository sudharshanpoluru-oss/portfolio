# 📖 About

This repository contains the source code for my personal portfolio website. It serves as a central hub where I showcase my projects, technical skills, certifications, achievements, and learning journey.

The portfolio is designed with a strong focus on performance, responsiveness, accessibility, and clean user experience, allowing visitors to explore my work across web development, full-stack applications, and AI/ML projects.

---

# ✨ Features

* ✅ Modern and responsive user interface
* 📱 Mobile-friendly design
* ⚡ Fast loading and optimized performance
* 👤 About Me section
* 🛠️ Skills & Technology Stack
* 🚀 Featured Projects showcase
* 📱 **College Hostel Management System** — Flutter mobile app + React.js/Node.js web app with Supabase backend. Three role-based logins (Admin, Warden, Student). Students self-register; wardens are scoped by hostel type (girls' hostel warden sees only girls' data, boys' hostel warden only boys' data). See [college_hostel_app](https://github.com/sudharshanpoluru-oss/college_hostel_app)
* 🎓 Certifications section
* 📧 Contact form
* 🧭 Clean and intuitive navigation
* 🌐 Social media integration
* 📂 Well-organized project structure

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/sudharshanpoluru-oss/portfolio.git
```

## Navigate to the Project

```bash
cd portfolio
```

## Run Locally

If using PHP:

```bash
php -S localhost:8000
```

Then open: `http://localhost:8000`
